# YouTube Loop — A-B Repeat

[English](README.en.md) · [Русский](README.ru.md) · [简体中文](README.zh-CN.md) · [Français](README.fr.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Deutsch](README.de.md)

プレーヤー内の A–B 操作で YouTube 動画の区間をリピートします。全画面表示にも対応。無料、MIT ライセンス、外部依存関係なし。

## インストール
リポジトリをダウンロードして展開します。`chrome://extensions` でデベロッパーモードを有効にし、「パッケージ化されていない拡張機能を読み込む」から `manifest.json` があるフォルダーを選びます。YouTube のタブを再読み込みしてください。ファイル更新後は拡張機能を再読み込みし、その後 YouTube を更新します。

## 使い方
通常の動画を開き、プレーヤー右下の **A–B** を押します。「現在の時刻に設定」で開始位置 A と終了位置 B を指定するか、時刻を入力し、「リピートをオン」を押します。パネルを閉じてもリピートは継続します。Escape で閉じ、「リセット」で区間を消去します。

時刻形式：`85.5`、`1:25.500`、`0:01:25.500`。区間は最低 0.2 秒です。リピート中に区間外へ移動すると A に戻ります。区間は動画ごとに保存されます。動画を切り替えるとリピートはオフになり、ページ更新後も手動でオンにします。

## 言語
Chrome の表示言語に従います。英語、ロシア語、簡体字中国語、フランス語、日本語、韓国語、ドイツ語に対応し、それ以外は英語になります。拡張機能のオプションで手動選択や自動選択への復帰ができます。変更は開いている YouTube タブにも適用されます。

## 制限とプライバシー
PC の `www.youtube.com/watch` に対応します。Shorts、ライブ配信、埋め込みプレーヤーは非対応です。広告中はリピートを中断します。バッファリングやバックグラウンドのタイマー制限により境界で遅延が生じる場合があり、シームレスな再生は保証しません。YouTube の変更に伴い更新が必要になることがあります。

区間と言語設定はローカル保存のみ。アカウント、解析、外部通信はありません。`storage` 権限は設定保存に使い、サイトへのアクセスは YouTube のみに限定します。

## 開発とライセンス
Node.js 18+：`npm test`。翻訳の変更後は `node scripts/build-locales.cjs`。依存パッケージのインストールは不要です。Chrome で再生、全画面、広告、画面遷移、保存、言語を手動確認してください。[MIT](../LICENSE)。YouTube や Google とは関係のない独立プロジェクトで、両社の承認は受けていません。
