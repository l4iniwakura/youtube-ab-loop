# YouTube Loop — A-B Repeat

[English](README.en.md) · [Русский](README.ru.md) · [简体中文](README.zh-CN.md) · [Français](README.fr.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Deutsch](README.de.md)

플레이어에 통합된 A–B 컨트롤로 YouTube 구간을 반복합니다. 전체 화면에서도 사용할 수 있습니다. 무료, MIT 라이선스, 외부 의존성 없음.

## 설치
저장소를 다운로드하고 압축을 풉니다. `chrome://extensions`에서 개발자 모드를 켜고 “압축해제된 확장 프로그램을 로드합니다”를 눌러 `manifest.json`이 있는 폴더를 선택하세요. YouTube 탭을 새로고침하세요. 파일 업데이트 후에는 확장 프로그램을 다시 로드한 다음 YouTube를 새로고침합니다.

## 사용법
일반 동영상을 열고 플레이어 오른쪽 아래의 **A–B**를 누르세요. “현재 시간으로 설정”으로 시작 A와 끝 B를 지정하거나 시간을 입력한 뒤 “반복 켜기”를 누릅니다. 패널을 닫아도 반복은 계속됩니다. Escape는 패널을 닫고, “초기화”는 구간을 지웁니다.

시간 형식: `85.5`, `1:25.500`, `0:01:25.500`. 최소 길이는 0.2초입니다. 반복 중 구간 밖으로 이동하면 A로 돌아갑니다. 구간은 동영상별로 저장됩니다. 다른 동영상으로 이동하면 반복이 꺼지며 새로고침 후에도 직접 켜야 합니다.

## 언어
Chrome 인터페이스 언어를 따릅니다. 영어, 러시아어, 중국어 간체, 프랑스어, 일본어, 한국어, 독일어를 지원하고 그 밖의 언어는 영어로 표시합니다. 확장 프로그램 옵션에서 언어를 직접 선택하거나 자동 선택으로 되돌릴 수 있습니다. 변경은 열려 있는 YouTube 탭에도 적용됩니다.

## 제한 및 개인정보
데스크톱 `www.youtube.com/watch`를 지원합니다. Shorts, 실시간 방송, 삽입형 플레이어는 지원하지 않습니다. 광고 중에는 반복을 중단합니다. 버퍼링이나 백그라운드 타이머 제한 때문에 경계에서 지연될 수 있으며 끊김 없는 재생을 보장하지 않습니다. YouTube 변경 시 확장 프로그램 업데이트가 필요할 수 있습니다.

구간과 언어 설정은 로컬에만 저장합니다. 계정, 분석, 외부 요청은 없습니다. `storage` 권한은 설정 저장용이며 사이트 접근은 YouTube로 제한됩니다.

## 개발 및 라이선스
Node.js 18+: `npm test`. 번역 수정 후 `node scripts/build-locales.cjs`를 실행하세요. 의존성 설치는 필요 없습니다. Chrome에서 재생, 전체 화면, 광고, 페이지 이동, 저장, 언어를 직접 확인하세요. [MIT](../LICENSE) 라이선스. YouTube 또는 Google과 제휴하거나 승인을 받은 프로젝트가 아닙니다.
