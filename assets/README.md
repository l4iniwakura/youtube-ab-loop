# Brand assets

- `logo.png`: original generated transparent PNG master.
- `logo-256.png`: 256 × 256 derivative for repository documentation.
- `../icons/icon-{16,32,48,128}.png`: resized Chrome extension icons.

Created on October 18, 2026 with the built-in ImageGen tool. Derivatives use Lanczos resizing; no manual redrawing. These assets are included under the repository's MIT license. No official YouTube logo is used.

## Generation prompt

Use case: logo-brand. Create a single polished standalone icon / brand mark for the independent open-source Chrome extension 'YouTube Loop — A-B Repeat'. No text or letters. A bold, beautifully balanced continuous repeat loop made from two substantial rounded arrows, enclosing a small right-pointing play triangle in negative space. Flat geometric graphic, mint teal #74dfc4 paired with deep charcoal #202020, matching a dark video-player interface. Compact square silhouette with generous crisp strokes that remain recognizable at 16px. Centered mark occupying approximately 85% of a square canvas, genuinely transparent surrounding background. No presentation board, no mockup, no multiple options, no gradients, no shadows, no hairline details. Entire logo must be original: do not reproduce YouTube's red rounded rectangle or its logo. Deliver one clean high-resolution raster master suitable for resizing into extension icons and use at the top of README documents.
